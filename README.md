# Room Makeover

Игра на чтение уровня A2: 8 комнат, 8 писем, по 6 предметов мебели. Все иллюстрации хранятся внутри проекта, внешние библиотеки, шрифты и серверная часть не нужны.

## Как разместить
Распакуйте ZIP. Загрузите **содержимое** папки в корень репозитория GitHub: index.html, style.css, data.js, game.js, папку assets и .nojekyll. Включите GitHub Pages для корня ветки с этими файлами. Не загружайте сам ZIP вместо файлов сайта.

Можно также открыть index.html непосредственно в браузере компьютера.

## Как играть
Выберите комнату кнопками 1–8. Прочитайте письмо. Перетащите мебель к овальному месту на полу либо нажмите на мебель, затем на место. Все места равнозначны: в них нет силуэтов или подписей правильной мебели. Слева и справа — с точки зрения игрока.

Проверка происходит автоматически только после расстановки всех шести предметов. Зелёные предметы со знаком ✓ стоят правильно и фиксируются. Красные со знаком × можно перемещать. Два неверных предмета меняются местами, если перенести один на другой. Чтобы убрать предмет, выберите его и нажмите Return. После исправления снова срабатывает проверка. Restart room начинает текущую комнату заново.

Кнопка Next room появляется после решения. Прогресс восьми комнат сохраняется локально в браузере. После восьми комнат доступен итоговый экран и Play again.

На компьютере и планшете в горизонтальной ориентации интерфейс занимает один экран. В вертикальной ориентации используется адаптивная раскладка с прокруткой для читаемого письма.

Письма адаптированы под предоставленные фоны: окно слева, дверь справа. В каждой комнате есть три задних и три передних места. Подписей мебели, переводов и показа решения нет. Доступные имена кнопок для экранных дикторов сохранены.

## Редактирование
Тексты, состав мебели и правильная расстановка находятся в data.js. Ответы перечислены в порядке: заднее левое, заднее среднее, заднее правое, переднее левое, переднее среднее, переднее правое. Статический сайт не скрывает ответы от просмотра исходного кода.
